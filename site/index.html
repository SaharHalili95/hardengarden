Your Linux system is a garden. HardenGarden finds the weeds.

A read-only security auditor for Ubuntu and Debian. It checks SSH, the firewall, permissions, sudo, accounts, updates and kernel settings, scores the machine, explains every finding with a local AI model, and hands you a reviewed fix you run yourself.

Download v0.1.0 Read the source

Free and open source (Apache-2.0). No account, no cloud, no telemetry.

How it works

  1. Survey

    Twelve checks read configuration files and three fixed commands (sshd -T, ufw status, nft list ruleset). Nothing is written, restarted or installed. The Garden Health score comes from a fixed formula, never from the AI.

  2. Explain

    A local model, run by Ollama on your own machine, explains each weed in plain language. Answers come from an original knowledge base and cite the passage they use. When the knowledge base does not cover a question, it says so instead of guessing.

  3. Fix it yourself

    Every finding has a reviewed shell script. It changes nothing unless you run it as root with HG_APPLY=1, backs up each file it edits, and checks SSH configuration with sshd -t before reloading.

The desktop app

A garden view of the whole machine, the list of weeds, and a detail page for each one with its evidence, the explanation and the script. The same scanner also runs as a command-line tool.

Recorded on the build machine, where Ollama was not installed, so the explanation shows how the app behaves without AI: scanning, scores and scripts still work.

What it will never do

  • Change your system. Checks only read. Fixes are text you review, copy and run.
  • Ask for your password. No sudo prompts, no privilege escalation. Run the scanner with sudo yourself if you want full coverage.
  • Send anything anywhere. The only network traffic goes to Ollama on your own machine. The local API listens on 127.0.0.1 with a per-launch token.
  • Let the AI decide. Findings and scores are deterministic. Text from your system reaches the model as data, and its answers are shown as plain text with commands and links removed.

Releases are signed with Sigstore and ship with checksums and an SPDX SBOM. CodeQL, Trivy, bandit and pip-audit run in CI. The full analysis is in the threat model.

Install

Ubuntu 22.04 or newer, or Debian 12, on x86_64. Download the files from the releases page.

Desktop app (.deb)

Installs the app and the hardengarden command.

sudo apt install ./hardengarden_0.1.0_amd64.deb
hardengarden-desktop

AppImage

Nothing to install. Make it executable and run it.

chmod +x hardengarden_0.1.0_x86_64.AppImage
./hardengarden_0.1.0_x86_64.AppImage

Command line only

With uv, which brings Python 3.12.

uv tool install ./hardengarden-0.1.0-py3-none-any.whl
hardengarden scan

For AI explanations, install Ollama. The app picks a model that fits your RAM and downloads it only when you click Download.

Good to know

HardenGarden is an educational and portfolio security tool. It is not a certified compliance scanner and does not replace a professional audit. Twelve checks cover the most common weeds, not every one. AI answers can be wrong, so read the passage they cite.

HardenGarden is open source under the Apache-2.0 license. The page loads nothing from other sites.
